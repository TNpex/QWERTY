# Исследование saletennis.com под авторизацией (2026-09-24)

> Как воспроизвести: session-cookie `PHPSESSID` (экспорт через Cookie-Editor из
> залогиненного браузера) + обычный HTTP (requests). Браузер не нужен — все
> таблицы рендерятся сервером. Привязки сессии к IP нет.
> ⚠️ Cookie — временный ключ: после завершения работ выйти с сайта, чтобы отозвать.

## 1. Таблица наличия (то, ради чего нужен логин)

`table.admin-sizes` на странице товара, две структуры:

**A) Товар с размерами** (обувь/одежда): строка = размер, во 2-й ячейке div'ы
«Магазин - N пар/шт»:
```
42,5 | Соболева - 1 пар | Санкт-Петербург (Ярослава Гашека) - 1 пар | ...
43   | Ижевск - 1 пар | Тюмень (Народная) - 1 пар | Парина - 1 шт | ...
```
Единицы: «пар» (обувь), «шт».

**B) Безразмерный товар** (струны/мячи/сумки): строка = магазин, во 2-й ячейке
«N сет/банка/кор/шт»:
```
Ижевск           | 12 Сет
Тюмень           | 4 Сет
Тюмень (Народная)| 3 Сет
```

## 2. Разгадка «46 товаров без информации о наличии»

Все 46 — **теннисные струны 12 м**. Таблица наличия на их страницах ЕСТЬ
(структура B, «N Сет») и видна даже в сыром HTML без JS. Данные на сайте
(снимок 2026-09-23 16:52 Екб) сделаны СТАРЫМ парсером, который строки
«магазин|количество» принимал за размеры и терял количество.
Улучшенный парсер (коммит 063ed0d) это уже чинит (`_match_store` + QTY_RE).
Actions-run #1 (запущен 23.09 22:18 UTC) работает на новом парсере — после его
завершения предупреждение про 46 товаров исчезнет само. **Правки парсера не нужны.**

## 3. ⚠️ «Тюмень» и «Тюмень (Народная)» — РАЗНЫЕ магазины на сайте

## 4. Корзина — полный API (проверено живым тестом add→get→delete)

| Операция | Запрос | Параметры | Ответ |
|---|---|---|---|
| Добавить | `POST /cabinet/cart/add/` | `item` = ID товара (число в конце slug URL = `data-item-id` кнопки), `count` = кол-во, `size` = **внутренний ID размера** или `0` (безразмерный) | `{"error":0}` |
| Корзина | `GET /cabinet/cart/get/` | — | HTML; строки `.js-cart-item[data-id=<ID строки>]`, `data-ecommerce` = JSON (id, name, quantity…) |
| Изменить кол-во | `POST /cabinet/cart/change/` | `item` = ID строки корзины, `count` | `{"error":0}` |
| Удалить | `POST /cabinet/cart/delete/` | `item` = ID строки корзины | `{"error":0}` |
| Счётчик | `GET /cabinet/cart/getcount/new/` | — | JSON (сумма, кол-во) |

- CSRF-токена НЕТ — авторизация только session-cookie. Заголовки: обычный
  `User-Agent` + `X-Requested-With: XMLHttpRequest` (не обязательны).
- **ID размеров** — из radio-инпутов `.card__sizes input[name=size]` на странице
  товара: `value="38495"` ↔ label «42,5». Их нужно собирать парсером в карту
  `cart-map.json`: {itemId, sizeText → sizeId} (~2200 товаров, страницы и так обходятся).
- JS-оригинал: `buySizeProductPage`/`buyWithoutSizeProductPage` → `sendBuyProductPage`
  → `$.ajax POST cart_add {item,count,size[,stringing,giftBox]}` (app.js ~14089).
- Услуги: `stringing=1` (натяжка), `giftBox=1` (подарочная коробка) — доп. флаги в add.

### Ограничение браузера (важно для фичи «корзина из Перемещений»)

Дашборд на `*.vercel.app` НЕ может дёргать `saletennis.com/cabinet/cart/add/`
напрямую — CORS заблокирует POST. Рабочие варианты:
1. **Букмарклет** (рекоменд.): кнопка «Перенести в корзину» открывает
   `https://www.saletennis.com/cabinet/cart/#st=<base64(JSON позиций)>`;
   пользователь кликает букмарклет (один раз перетащенный в панель закладок) —
   он на странице saletennis (same-origin, с его сессией) декодирует hash и
   последовательно POST-ит cart_add, показывает прогресс. Лимит URL ~2000
   символов → пачками по ~40-60 строк.
2. **Userscript (Tampermonkey)** — то же, но автоматически при открытии корзины.
3. Fallback без JS: «Скопировать список» / XLSX + открыть корзину вручную.

## 5. Личный кабинет

`/cabinet/` = «Мои заказы» (~20 МБ, вся история заказов аккаунта, ссылки
`/cabinet/orders/<номер>/`). Потенциал на будущее: реальные данные закупок
(что/когда/сколько заказывали у поставщика) — для прогноза дозакупки.
Отдельных страниц «мастер-таблицы остатков» нет — остатки только по товарам.

## 6. Каталог (публично, без логина)

- Список товаров + «Размеры 38,5, 40,5» (доступные размеры без магазинов).
- Фильтры сайта содержат официальные списки брендов по категориям (Diadora,
  Tecnifibre, Mizuno, Bidi Badu, 7/6, …) — справочник для автоопределения брендов.
- ID товара = число в конце slug (`...-17063` → 17063) = `data-item-id`.
